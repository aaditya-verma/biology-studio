## 4. Content model
Ids, book codes, tiers, audience levels, threads, marks, gates → `claude/README.md`. **Concept** (K1) = a row in the concept map; it becomes a card with the same id. Card = one screen + More: **objective** · idea · 3D view · Watch it · Try it · Remember · More (incl. "Newer evidence" / "beyond Langman") · Clinical link · Where it shows up · Check · Sources · AN code. Episode (60–180 s default) = cold open ≤ 10 s (question/mystery) → terms strip → 3 beats (ABT, one objective each) → "this becomes…" → recap → 2-question Check; core ×2 / support ×1. **Audience profile** per episode: level (General · School · NEET · MBBS · PG), depth tier, type (lesson [was explainer, D-046] · story · quick recap · short), format (16:9 · 9:16; Lesson vs Short → `build/visual-style.md` §10), length, **language (English default · Hinglish · Hindi)**, **host (cell/embryo character default · animal · stylised human · none)** (D-032); cuts `S1E01-gen`, `S1E01-short`. Short grammar + host rules → playbook §5b. Story formats: Journey · Mystery · Factory · Character · Countdown; Season 1 question: *How does a flat disc become a body?*

## 6. Content production — Research → Draft & review
K1 rows + X1 dossier for the chapter → pick concepts → write objectives → Studio drafts from the book + dossier (own words, cited, marked; refutes listed misconceptions) → validator (citations exist, marks present, ⚑ has a D-entry, ✚ only in More/Tier D, ≤ 25-word sentences, ≤ 3 new terms, glossary coverage, one right answer, Check matches objective) → **fresh-eyes review** (G-Sci, G-Learn, G-A11y) → owner reviews line by line → any ≈ left? yes → redraft; no → approved, permanent id, imported. Calibrate first: ≥ 90 % of glossary terms placed (I1: 98.9 % by text search, as the PDF has no Index — D-026).

## 7. Video production (local-first, D-014; craft per playbook §5–7)
Brief + audience profile (incl. language + host) → objectives → cited script (ABT) → table read (scratch TTS) → storyboard → shot list → scenes (checked against R01/R02) → **animatic in three.js with scratch voice** (host as placeholder) → gates G-Sci, G-Learn, G-Story, G-Art → final render on the laptop GPU (tool from M1; cinematic look per playbook §6; `--preview` first) + host shots (tools from M1b) → final voice (pronunciation dictionary, 130–150 wpm) + mix (−14 LUFS) + captions/transcript (drift < 100 ms; kinetic for Shorts) → ffmpeg assemble (NVENC H.264; x264 veryfast fallback) → **renditions per §8a** (720p phones; 1080p tablet/desktop rung if M1 allows) → QC (G-Eng, G-A11y, General-cut clarity, episode checklist, **plays well on phone, tablet and laptop**) → render manifest → publish to Drive + catalog + card clips → measure (recall, completion, drop-off). Meshes procedural where possible; glTF (.glb) between Blender and three.js; third-party assets only with approved licences (Z-Anatomy adult meshes in rendered video only, D-021).
